# AI Prompt Maker（AIプロントメーカー）🚀

AIの力を最大限に引き出すための、最適なプロンプトを自動生成・調整できるWEBアプリケーションです。
HTML、CSS、JavaScript（Vanilla JS）のみで構成された、軽量で安全に動作する完全フロントエンドツールです。
👉 **[デモサイト（GitHub Pages）で動かしてみる](https://warahagi.github.io/Prompt-Maker-JS)**

---

## 🌟 主な機能

1. **簡単・直観的なプロンプト自動生成**
   - AIの役割（Role）と、具体的な目的・タスク（Goal）を入力するだけで、Geminiが最も理解しやすい効果的なプロンプトの骨子を作り上げます。
2. **安心なセキュア設計（APIキーローカル保存）**
   - 入力されたGemini APIキーはブラウザ上のメモリでのみ使用され、外部サーバーなどへ送信されることは一切ありません。安心してお使いただけます。
3. **選べる出力形式**
   - 箇条書きやステップ形式など、目的に合わせた最適なフォーマットをドロップダウンメニューから簡単に指定できます。
4. **今日のプロンプト運勢占い　🔮**
   - "今日はどんなプロンプトと相性がいい？" "作業運は？" など、開発中の息抜きやインスピレーションに使えるお遊び占い機能を搭載しています。
---

## 🛠️ 使用技術

- **HTML5** / **CSS3**（レスポンシブデザイン・モダンUI）
- **JavaScript（Vanill JS）**
- **Gemini API**（Google AI SDK / Web統合）

---

## 🚀 使い方

1. **デモサイトにアクセス**するか、このリポジトリをクローンして `index.html` をブラウザで開きます。
2. **Gemini API Key** を入力します。
   - ※ APIキーをお持ちでない場合は、[Google AI Studio](https://aistudio.google.com/) から無料で発行できます。
3. AIに演じさせたい **「AIの役割（Role）」**（例：*プロのUXデザイナー、熟練のPythonエンジニア*）を入力します。
4. 解決したい **「目的・タスク（Goal）」**（例：*新しいマッチングアプリのペルソナ設計を作ってほしい*）を入力します。
5. 好みの **出力形式（Format）** を選択します。
6. **「最適なプロンプトを生成する」** ボタンをクリックすると。目の前でプロンプトが自動生成されます！
